# V1 阶段总结

日期：2026-09-19

## 结论

V1 规划中的最小科研闭环已经实现并通过一个真实公开 AI 案例验收。系统能够从结构化任务开始，检索和登记证据，形成可证伪假设与实验计划，在人工审批后执行基线和候选实验，保存代码、数据、模型和预测哈希，分析结果，进行独立审查，记录审查响应，并在最终人工确认后结束。研究状态、模型原始输出和决策事件保存在 SQLite，进程中断后可以从当前阶段继续。

本阶段证明的是 pipeline 能运行且能保存审计证据。它不证明 agent 已能自主提出可发表成果，也不包含跨项目长期记忆、并行研究树或多学科实验执行。

## 真实案例结果

案例协议见 [fastText AG News 方法检查](cases/fasttext-agnews.md)。运行 ID 为 `b496c6dd-4da3-4322-8dc5-0afd26f36596`，最终状态为 `done`，共使用 6 次模型调用。数据和模型保存在忽略版本控制的 `.research-data/`。

- unigram 基线平均 accuracy：`0.9093859649`
- bigram 候选平均 accuracy：`0.9190789474`
- 平均差：`+0.0096929825`，即 `+0.969` 个百分点
- 三个配对种子的差分别为 `+0.0090789474`、`+0.0105263158`、`+0.0094736842`
- 基线三个运行合计正确 `20,734 / 22,800`；候选为 `20,955 / 22,800`

因此，在固定的 AG News 文件、fastText 二进制、超参数和种子 11、23、47 下，`wordNgrams=2` 的平均准确率高于 `wordNgrams=1`。这是对该配置的描述性结果。三个训练种子共享一个测试集，不能支持跨数据集的一般因果或统计显著性结论。

独立审查最初给出 `needs_work`，指出决策规则、完整数据哈希和构建环境记录不足。系统要求先提交结构化审查响应才允许最终确认。响应补充了三份预处理数据的独立哈希、归档与 manifest 哈希、fastText release 与二进制哈希、编译器/系统信息、精确计数和描述性不确定性范围，并保留剩余局限。

## 已知限制和下一阶段入口

1. 模型费用目前用调用次数限制；代理未提供可信单价，因此没有美元金额硬上限。
2. `paper-search` 可以联网执行，全文获取、引用段落定位和去重仍需加强；本次搜索也返回了若干低相关论文。
3. 方法型 skills 已进入阶段提示并验证加载，混合型 skill 的每个辅助脚本尚未全部做语义级测试。
4. 默认实验隔离使用 Docker，但真实案例因使用可信、固定哈希的本地脚本而显式选择进程模式。
5. pi 会话不是研究事实源；当前长期记忆是账本与文件。跨项目检索、经验压缩和遗忘策略属于下一阶段。
6. 当前只验证 AI 文本分类场景。规划中的第二种研究场景不属于 V1 最小验收，将在后续用于检验通用接口。
