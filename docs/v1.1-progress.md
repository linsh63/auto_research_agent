## A 阶段过程记录

### 已完成

- 读取并落实 v1.1 规划中的 SQLite schema、内容寻址存储、配置和 worker 边界。
- 将数据库 schema version 从 V1 的 1 迁移到 2；旧 run 保持可读。
- 添加 `SourceRecord`、`DocumentVersion`、`Passage`、`Claim` 和 `ClaimEvidence` domain schema。
- 添加 evidence 表、FTS5 passage 索引、Claim-Evidence 关系和检索事件表。
- 添加 SHA-256 content-addressed artifact store。
- 添加项目 YAML 默认配置和 Zod 校验。
- 添加 JSONL retrieval worker、handshake、deadline、cancel 和崩溃清理。
- 安装独立 PaperQA2 `2026.8.12` worker 环境，固定 `requirements.lock.txt`；worker capability 已报告 `paperqa`。
- 添加 V1 证据迁移脚本，将 fastText run 的 12 个来源、12 个 document version 和 9 个摘要 passage 写入新库。
- 现有搜索流程已默认尝试 retrieval worker；worker 不可用时保留 paper-search fallback。
- 添加 `evidence-status`、`evidence-search`、`retrieval-check` CLI。

### 当前待验收

- CanonicalDocument 的 GROBID/Docling 生产解析 adapter；当前 metadata/abstract ingestion 已通过，完整 PDF parser 仍需在本阶段补齐。
- PaperQA2 实际全文 ingestion/evidence gathering smoke test。
- 40 条检索评测集、LitQA2/LFRQA 固定子集和 citation support 标注。
- A 的数据库迁移、故障注入和完整回归门禁。

### A 阶段最终登记

详见 [v1.0.1 release report](releases/v1.0.1-report.md)。控制平面、数据库、worker、PaperQA2 capability、迁移、降级路径和离线门禁已完成；GROBID 容器和 Docling 完整解析因当前运行环境不可用，按降级规则记录为环境限制。
