# v1.3 B/C 联合迭代计划

## 总目标

让 Agent 在四个人工门以内，完成一项机制驱动、可证伪、使用自然场景数据的多模态研究；Agent 必须根据中间证据自主选择下一项实验，并形成经过事实账本审计的有界结论。

## C：真实研究问题

暂定问题：训练外的选择性反事实验证，能否让多模态模型根据问题语义决定读取或忽略场景文字，在抵抗误导文字的同时保留正常 OCR 与文字推理能力？

候选数据以 RIO-Bench 的 same-scene read/ignore counterfactual 设计和 SCAM 的真实 typographic attack 图像为优先；获取和许可核查完成前不冻结 protocol。

### 预备假设

- Target：选择性路由优于直接推理，并优于总是遮罩文字，在联合 read/ignore 效用上获得有意义提升。
- Null：选择性路由没有超过直接推理与简单提示词的稳定收益。
- Rival A：收益仅来自 OCR 成功样本，机制是恢复干净输入，而非更好的证据选择。
- Rival B：收益由某一模型、问题类型或文字显著度驱动，不能跨条件保持。

### 最小实验结构

- 独立单位：原始自然图像；同场景问题、文字条件和方法为重复测量。
- 条件：应读文字、应忽略文字、无关文字、无文字对照。
- 基线：直接回答、冲突提示词、总是遮罩、上一版 OCR overlap 遮罩。
- 候选：由 B 阶段决策引擎选择的训练外反事实路由方案。
- 模型：至少两个本地开源 MLLM。
- 主要结果：read/ignore 两类任务等权后的图像聚类联合效用。
- 约束：清洁/应读任务非劣、平均推理次数和 GPU 时间上限。

## B：科研决策能力

### B1 决策对象

实现 `ScientificDecision`：输入冻结假设、FactLedger、资源余量和可选实验；输出动作、被区分的假设、预期信息增益、成本、停止条件和事实引用。

### B2 判别实验选择

实验候选必须说明能区分哪个 rival。禁止仅因预期准确率更高而选择实验。优先级由判别价值、风险、成本和确认集边界共同决定。

### B3 序贯决策

至少完成两次真实的自主决策：一次在探索中选择机制实验，一次决定继续、确认、重设计或停止。每次决策先登记，结果揭示后不可改写。

### B4 决策审计

错误事实引用、没有 rival、没有停止条件、超预算、重复查看确认集或事后新增主要结果均阻止决策。

## 阶段划分

1. **B1/C1：** 决策 schema 与状态机；数据、许可、模型和基线可行性。
2. **B2/C2：** 冻结竞争假设；运行小规模探索，由 Agent 选择判别实验。
3. **B3/C3：** 机制消融和跨模型检查；Agent 作出第二次序贯决策。
4. **B4/C4：** candidate gate、一次性确认、四维评审和最终报告。

## 联合验收

- 四个人工门外不需要人工修改实验选择或统计事实。
- 至少两个 ScientificDecision 有完整事实来源并在结果前登记。
- 最终实验能削弱或支持至少一个 rival，而不只报告方法排名。
- 所有核心数值经过 `fact_bound_v1`，无人工修正数据集、模型、区间或范围。
- 正负结果都能生成明确的停止或后续研究决定。
