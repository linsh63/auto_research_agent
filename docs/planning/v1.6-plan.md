# v1.6 规划：公共科研能力与跨系统开发

状态：实施中。U 阶段已完成；V 阶段跨系统开发与执行能力待实施。

## U：七类公共科研能力

目标是让独立 CLI、Web、游戏和第三方客户端只经 Core Service/SDK 使用 v1.5 已有的科研门禁。范围包括：文献全文证据、创新性边界、竞争假设、实验设计与混杂、统计与实验单位、记忆审核复用、事实绑定科学写作。

验收条件：

1. 七类能力进入版本化公共 command/query schema 和 TypeScript/Python SDK。
2. 每类 success 与 adversarial fixture 都通过真实 Core Service 调用。
3. scope、Workspace/Project 隔离、人工 memory verification、事实与实验单位门禁不可绕过。
4. 调用写入 ResearchEvent，进入权限审计和 Bundle v2 状态。
5. T3 v1.1 的七个 `not_evaluated` 归零，相同实现双跑稳定。

状态：**完成**。结果为 10 demonstrated、2 partial、0 not_evaluated、0 failed。

## V：跨系统开发与执行能力

后续重点验证 macOS、Linux 和 Windows/WSL 的安装、Core Service、SDK、SQLite、Bundle 和本地 Worker。Bubblewrap 保持 Linux capability；其他系统通过能力协商使用本地有限 Worker或远程 Linux Worker。该阶段尚未开始，不属于 U 的完成判定。
