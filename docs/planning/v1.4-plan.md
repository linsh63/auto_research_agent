# v1.4 规划：泛化、机制诊断与隔离确认

状态：已完成。最终验收见 [v1.4 阶段报告](../reports/stages/v1.4-progress.md)。

## 总目标

验证 Agent 能否把 v1.3 的 read/ignore 结论迁移到未见问题模板、任务族和模型，并自主发现失效边界。v1.4 不把 query-aware text editing 作为新颖方法贡献；近期 QuISE 等工作已覆盖相邻思路。本阶段的贡献类型是严格 transport/replication study 和 Agent 能力验收。

## 科学问题

冻结的 semantic router 在移除 RIO 固定问题措辞后，是否仍能维持 read-required 与 ignore-required 联合效用？哪些因素导致失败：问题模板、OCR 命中、文字显著度、模型规模，还是数据集差异？

## 竞争解释

- Target：路由依据的是问题的语义需求，跨模板后仍保留方向。
- Null：跨模板平均效应低于最小有意义边界。
- Template rival：v1.3 收益来自固定字符串规则，而非语义判断。
- OCR rival：收益只出现在 OCR 正确覆盖攻击词时。
- Model rival：收益由某一模型结构或规模驱动。
- Dataset rival：RIO 效应无法 transport 到真实 SCAM 或其他 text-required 数据。

## 设计

- 独立单位：原始图像。
- 重复测量：任务族、原始/攻击视图、模板族、方法、模型。
- 模板：至少两个未用于 v1.3 的同义改写族，并保留原模板作锚点。
- 任务：object-ignore、scene-text-read、至少一个不同形式的自然文本任务。
- 模型：至少三个本地 MLLM 或模型规模。
- 主要 estimand：候选相对 direct 的跨模板图像级平均效应。
- 关键交互：method × template、method × OCR-hit、method × model。
- 预注册 transport 成功：平均效应达到边界、模板间方向一致、read-task 非劣、至少两个模型方向一致。

## Agent 能力目标

1. 自动生成模板、OCR、模型和数据集 rivals，并形成预测矩阵。
2. 先登记 ScientificDecision，再选择最有判别力的模板/模型实验。
3. 根据中间事实自主决定扩大模板、增加模型、重设计或停止。
4. 禁止用固定关键词规则作为最终 router；候选必须处理未见措辞。
5. confirmation 必须使用 bubblewrap，运行前通过 GPU/runtime preflight。
6. LLM facts 的格式修复必须自动记录，最终 claim 仍由 FactLedger 精确渲染。

## 阶段

- J：prior-art、transport question、模板与任务 manifest。
- K：语义 router 与模板不变性决策引擎。
- L：三模型探索和机制交互分析。
- M：候选冻结、bubblewrap confirmation、四维评审、最终发布。

## 验收

- 至少三次真实 ScientificDecision，其中一次必须选择停止或扩大某个边界实验。
- 至少三个模型、三个任务条件、三个模板族。
- 图像级聚类分析，没有模板或问题伪重复。
- confirmation sandbox run 中存在成功的 `bubblewrap` 记录；trusted-only confirmation 阻止最终发布。
- 最终报告明确区分 replication、transport、mechanism inference 与新颖方法 claim。
- 全量测试、迁移、故障注入和真实研究门禁全部通过。
