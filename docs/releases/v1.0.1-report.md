# v1.0.1 A 阶段发布报告

日期：2026-09-19

范围：证据、全文、引用与成熟检索 worker

## 实际完成

- SQLite schema version 从 1 迁移到 2；V1 fastText run 保持可读取。
- 新增 Source、DocumentVersion、Passage、Claim、ClaimEvidence、retrieval event 表和 FTS5 索引。
- 新增 SHA-256 内容寻址 artifact store。
- 新增 YAML 配置、Zod 校验、资源默认值和可编辑检索参数。
- 新增 PaperQA2 `2026.8.12` 独立 Python 环境、`requirements.lock.txt` 和 `uv.lock`。
- PaperQA2 import、Tantivy、`Docs.aadd_texts` smoke test 通过；worker handshake 报告 `paperqaAvailable=true`。
- 新增 JSONL stdio retrieval worker，支持 handshake、health、metadata search、PaperQA2 text ingestion、deadline/cancel和 worker restart 清理。
- 现有 pipeline 默认尝试 retrieval worker；worker不可用时回退到 paper-search。
- 新增 metadata/abstract ingestion 和旧 V1 evidence migration；fastText run 已迁移为 12 sources、12 document versions、9 passages。
- 新增 canonical text/PDF parser adapter。HTML/XML、GROBID和Docling接口边界已预留；当前本机 PDF fallback 使用 `pdftotext`。Docker daemon 当前不可访问，因此未执行 GROBID service smoke test；Docling slim 可安装，但完整 PDF pipeline 的 `docling_parse` extra 未安装，相关降级已记录。
- 新增 evidence status/search、retrieval check、file ingestion CLI。
- 新增 40 条项目检索 fixture 和可重复评估脚本。

项目 fixture 是 V1 fastText 来源集合，先验证索引、查询和 provenance 链路；LitQA2/LFRQA 固定子集的完整运行需要在 worker 具备其公开数据和 embedding 配置后执行。当前 40 条结果的关键论文命中率达到预设 0.90 门槛，但不能替代科学问题集上的语义评测。

## 主要限制

1. PaperQA2 当前已安装并可 ingest 文本，但默认 metadata search 仍使用现有 paper-search connector；完整 PaperQA2 agentic evidence gathering 需要配置 evidence model 和 embedding backend。
2. 本机 Docker daemon 权限不可用，GROBID 容器未运行；当前使用 pdftotext fallback，解析警告会进入 CanonicalDocument。
3. Docling 完整 standard extra 会引入大型 torch/CUDA 依赖，当前未安装；Docling adapter 保留为可选能力。
4. 40 条 fixture 主要测试 exact/title metadata 命中，尚未完成人工标注的 citation support precision 和 nDCG 数据集。

## 发布判断

A 阶段的控制平面、事实库、worker 协议、PaperQA2 capability、降级路径、V1 迁移和离线门禁已完成。完整全文解析和语义 benchmark 属于已登记的环境依赖限制；在当前机器上默认安全路径是 PaperQA2/Tantivy + metadata/abstract ingestion + pdftotext fallback。下一阶段 B 可以开始，但 A 的全文和语义 benchmark 缺口必须在后续 release report 中继续追踪。
