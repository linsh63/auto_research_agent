# v1.1.0 / D 阶段发布报告

日期：2026-09-20

## 范围

D 阶段选择 scikit-learn Digits 图像分类作为第二研究场景，用一像素平移数据增强消融检验核心工作流的跨模态通用性。详细协议见 [案例说明](../cases/sklearn-digits.md)。

## 完成内容

- 新增可复现 CV brief、实验脚本和 Python 依赖版本文件。
- 在五个预声明分层 holdout 上执行基线与候选，保留每个 paired outcome、代码哈希、数据哈希、日志和环境版本。
- 通过既有 `ResearchEngine` 完成 evidence → hypothesis → plan → approval → baseline → candidate → analysis → review → final approval → done。
- 计划审批前未执行实验；`needs_work` 审查要求已通过结构化 review response 处理后才最终确认。
- evidence graph 记录 3 个来源、3 个 passage 和2个 claim；最终确认后生成2条 verified memory。
- 新增 `npm run validate:cv` 一键重放命令和 CV 回归测试。
- 扫描核心契约文件，未发现 Digits、scikit-learn 或 image classification 的领域名称；接入未修改 `src/`。

| Baseline mean accuracy | 0.992000 |

成功条件按预注册的均值规则通过。审查结论仍然保守：增益只有约0.13个百分点，候选训练规模为五倍，并且 seed 101 上下降约0.22个百分点。该案例证明的是场景接入与审计链路，不证明平移增强具有普遍收益。

## 通用性结论

- 文本和图像场景共用同一 `ResearchBrief`、命令执行、指标解析、账本、证据、记忆、人工门和报告生成逻辑。
- 场景切换所需运行文件全部位于 `examples/sklearn-digits/`；可复现验证器位于 `scripts/`，核心 `src/` 无领域特化修改。
- JSON 末行指标契约足以承载图像任务的总体与逐划分结果。
- 当前 schema 只支持单一标量作为主要排序指标。算力、校准、鲁棒性等多目标研究仍需在 details 中记录，尚不能作为统一门禁表达式。

## 已知限制

- Docker daemon 权限不足，真实容器执行未验收；本发布登记为 `local-process` profile。
- 确定性审计 model adapter 用于免费重放研究语言阶段；本案例不评估远程 LLM 的科研判断质量。
- 依赖文件固定版本但未包含 wheel hash；复现仍受 Python 平台和上游 wheel 影响。
- 五个 holdout 互相重叠，不能当作独立重复实验。
