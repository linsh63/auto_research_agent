## 实际完成

- 新增 search run、experiment node、parent/lineage、metric、失败和资源字段。
- 实现 linear 和 bounded best-first strategy port。
- 实现 candidate budget、wall time、cost、candidate count 和 concurrency 参数。
- 实现 train/validation/test/audit role schema 与 sealed test 校验。
- 实现候选失败分类、节点复用签名字段和完整节点 JSON 记录。
- 将 fastText/AG News 训练集确定性拆为 112,000 train 与 8,000 validation；published test 未挂载到搜索脚本。
- 运行相同 2-candidate 预算的 linear/best-first 对照：linear 最高 validation P@1 为 0.911，priority-guided best-first 为 0.922。
- 最佳候选为 `wordNgrams=2, epoch=5, dim=10`，节点日志、参数和 validation 结果写入忽略版本控制的 `.research-data`。
- 保留 Docker/ GPU scheduler port；当前主机 Docker daemon 无权限，因此 C 的本地验收使用受控 process runner，GPU Docker 集成留作环境条件满足后的补充测试。

## 限制

1. best-first smoke 使用预先给定的 candidate priority，证明调度接口和预算行为，不等于已证明通用启发式优于 linear。
2. 当前 patch mode、Docker GPU scheduler 和 confirmation seeds 只有 schema/port 与部分测试，尚未在本机 GPU Docker daemon 上实跑。
3. C 的正式统计确认需要在后续真实搜索任务中预注册新 seeds 和停止规则。

## 发布判断

C 的有界搜索控制面、数据隔离契约、节点审计、失败保留和低成本 fastText 对照已完成。best-first 保持 experimental，linear 仍是可用基线；任何研究任务必须在批准后才可运行自动搜索。
