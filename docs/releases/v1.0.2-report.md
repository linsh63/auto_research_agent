# v1.0.2 B 阶段发布报告

日期：2026-09-19

范围：长期研究记忆

## 实际完成

- 新增 memory items、namespace、relations、promotion、access log 和 job-ready schema。
- 实现 `candidate → reviewed → verified → superseded/retracted/archived` 状态门禁。
- verified/reviewed 才可默认召回；candidate 不会注入研究上下文。
- 实现 project/run/workspace 过滤；当前 CLI 默认检索 project/run scope。
- 实现 FTS5 memory search 和 provenance 字段；embedding 仍作为后续可重建索引。
- 实现 correction/promote/retract/archive/purge 数据操作；purge 生成 hash proof 并删除 memory text、FTS 和 relations。
- 记忆结构包含 source run、evidence IDs、适用范围和失效条件字段。
- 添加 memory CLI：status、search、add、promote、purge。
- `evaluate_memory.ts` 运行了 verified/candidate 隔离、负结果召回和 workspace 隔离检查。

## 限制

1. 当前 memory search 使用 SQLite FTS5，尚未接入 embedding 召回；这是可替换的派生索引，不影响事实库。
2. promotion job 目前由 CLI/服务调用，尚未加入独立后台队列。
3. broken provenance 扫描和大型 workspace 的性能压测留到真实多 run 数据积累后。

## 发布判断

B 阶段的记忆状态、作用域、冲突关系接口、审计和 purge 门禁已完成。长期记忆默认只对 verified/reviewed 且在允许 namespace 内的对象开放；跨 run 效率收益待真实项目数据验证，不以未经测量的收益宣称完成。
