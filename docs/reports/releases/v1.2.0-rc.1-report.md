## 真实案例

问题：固定 ResNet-18、三颗 seed 与单 GPU 下，AugMix 是否改善预声明 CIFAR-10-C 保留组的 mean corruption accuracy？

### Frozen design

- seeds：11、23、47；固定12 epochs；
- exploration：brightness、defocus blur，severity 3；
- confirmation：Gaussian noise、contrast，severity 3；
- experimental unit：training seed；corruption group 为 repeated measure；
- primary：seed 内 group 均值的 candidate-minus-baseline paired difference；
- minimum meaningful effect：0.01；95% t interval；
- clean accuracy 与 ECE 为 secondary；worst-group 为 exploratory。

### Confirmation result

| Seed | Baseline | AugMix | Difference |
| ---: | ---: | ---: | ---: |
| 11 | 0.63275 | 0.79330 | +0.16055 |
| 23 | 0.64250 | 0.79290 | +0.15040 |
| 47 | 0.63465 | 0.76640 | +0.13175 |

- estimate：+0.14757；
- 95% interval：[+0.11128, +0.18386]；
- n=3 independent seeds；6/6 group pairs complete；
- leave-one-seed-out：0.14108、0.14615、0.15547；
- ClaimAssessment：suggestive。

完整边界见 [案例报告](../../cases/cifar10c-augmix-h.md)。
