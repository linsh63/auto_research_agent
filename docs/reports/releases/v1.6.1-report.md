# Research Explorer Core 1.6.1

- Status: published
- Date: 2026-10-06
- Source commit: `60cf2d3dec17a921dce5641359ab0d1e02eae39b`
- Package: `research-explorer-core@1.6.1`

This patch publishes the public `workspace.projects` query used by Research
Explorer CLI 0.2.0. It returns bounded Project summaries ordered by recent
projection activity and includes branch, lifecycle status and display fields.
An empty or not-yet-created Workspace returns an empty list, allowing a fresh
installation to open the Project picker before its first Project exists.

Validation covered generated JSON schemas and Python models, public boundary
checks, a clean package-only consumer, and the complete 114-test Core suite.
