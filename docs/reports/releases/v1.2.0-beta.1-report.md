## 结论

G 阶段完成。系统已将 frozen research protocol 接入 Study、bounded exploration、CandidateFreeze、一次性 confirmation capability、ObservationTable 和确定性统计分析，并在当前主机真实验证无网络 bubblewrap 与单 GPU 映射。

## 统计 Oracle

固定3个训练seed、2个corruption group。Python NumPy/SciPy作为独立oracle。

| 检查 | 最大误差 | 容差 |
| --- | ---: | ---: |
| Mean difference | 0 | 1e-4 |
| Standard error | 6.94e-18 | 1e-4 |
| Interval endpoints | 1.01e-5 | 1e-4 |
| Paired effect size | 8.89e-16 | 1e-4 |
| Holm adjusted values | 7.74e-10 | 1e-6 |

复现：`python3 scripts/statistics_oracle.py` 与 `npm run evaluate:statistics`。

## Sandbox 实测

`npm run validate:bubblewrap` 在本机实际执行：

- network namespace：连接返回 `ENETUNREACH`；
- CPU/process/address-space/file-size限制：通过 prlimit 继承和sandbox内NPROC限制；
- GPU：独立workspace中的生成式probe代码在sandbox内运行，只绑定 `/dev/nvidia0`、control和UVM设备；`nvidia-smi -L`只显示批准设备；
- secret-like环境变量：拒绝；
- timeout与进程组回收：已有 runner test 覆盖。

## 门禁

- baseline不在容差内：study进入 `baseline_failed`，exploration被拒绝。
- confirmation role在CandidateFreeze审批前不返回。
- token错误、重复消费和未批准candidate：拒绝。
- confirmation后exploration observation：拒绝。
- seed是独立单位，corruption group作为重复测量。
- 缺失值、诊断、multiplicity和sensitivity进入结构化结果。
- 搜索失败和负结果继续保留在SearchStore。
