# v1.2.0-alpha.1 / E 阶段发布报告

日期：2026-09-20  
范围：研究协议与认知对象

## 结论

E 阶段已完成。系统现在有独立的版本化研究图和确定性状态门禁，能够在不破坏 v1.1 线性流程的前提下表达问题版本、scope approval、protocol approval、protocol freeze、deviation、confirmation visibility 和派生 run。

- [ADR 002](../../architecture/decisions/002-e-research-state-and-compatibility.md)：状态图、迁移和兼容策略。

- `src/infrastructure/db/research-store.ts`：schema 3 migration、备份、事务、canonical hash、状态查询和不变量。

- `research` CLI：intent、question、scope、protocol、freeze、deviation、visibility、derive、status。
- `smoke`、`exploratory`、`confirmatory` profile；旧 Brief 默认 smoke，ResearchIntent 默认 confirmatory。

## Migration 与回滚

ResearchStore 在执行 003 前创建 `backups/research-before-003-*.db`。回滚只在停止服务后恢复到新的验证目录，再通过 schema/version 和旧 CLI readback 检查；本阶段没有覆盖原数据库的自动回滚命令，避免误删新写入对象。
