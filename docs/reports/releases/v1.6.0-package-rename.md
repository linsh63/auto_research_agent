# v1.6.0 npm package rename

- Status: complete
- Date: 2026-10-05
- Repository: `linsh63/research_explorer_core`

The stable Core package is now `research-explorer-core@1.6.0`. The previous
`auto-research-agent` package remains available for reproducible existing
installations and is deprecated with a message directing users to the new
name.

Public TypeScript subpaths moved to the new prefix without changing their
contracts. The service and public schema versions remain `1.0.0`. The new
`research-explorer-core` executable is the preferred command;
`auto-research-core` remains an executable alias for compatibility.

Validation covered type checking, 114 Core tests, public boundary checks,
contract and Python SDK generation checks, documentation links, a package-only
consumer installation, and a clean unauthenticated installation from the
public npm registry.
