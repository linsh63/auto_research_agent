# E 阶段第三次验收整改清单

日期：2026-09-20
结论：**`v1.2.0-alpha.1-r2` 仍不合格，E 继续打开，F 保持阻塞。**

23项测试全部通过，但 protocol provenance 和 aggregate 版本链仍存在可绕过路径。

## P0：发布阻断项

1. **Protocol 必须绑定明确版本。** `ResearchProtocol` 当前没有 `assumptionRegisterId` 和 `hypothesisSetId`；`addProtocol` 只检查任意 frozen aggregate 是否存在。为 protocol 增加两个必填引用，写入 content hash，并验证它们属于当前 selected question、状态为 frozen。Deviation 产生的新 protocol 必须继承或显式替换这些引用。
2. **禁止并行根版本。** 当 AssumptionRegister/HypothesisSet 已存在时，新版本必须提供当前 active version 作为 parent；不得再次用 `parentId=null` 创建旁路分支。protocol 也应验证 parent 属于同一 program/question，并明确 supersede 关系。
3. **补版本 provenance 测试。** 构造两个 frozen 版本，确认 protocol 只能引用指定版本；错误 question/program、superseded、draft 和无 parent 分支均应拒绝。

## P1：证据收口

- artifact manifest 测试目前只断言 path/size，没有核对 SHA-256；补充固定摘要断言。
- CLI contract 目前只覆盖未知命令；补缺参和非法状态的非零退出码。
- r3 report 为每个 E 任务和退出条件列出具体测试名称。
