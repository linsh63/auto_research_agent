## 最终实现

- ResearchIntent、ResearchQuestion、AssumptionRegister、HypothesisSet、ResearchProtocol 和 run derivation 均为版本化对象。
- Protocol 强制保存 frozen `assumptionRegisterId` 与 `hypothesisSetId`，并将引用纳入 content hash。
- Aggregate 新版本必须指向同 question/program 的 latest frozen parent；父版本被原子 supersede，旁路根和错误范围被拒绝。
- Deviation 采用 pending request、独立批准完整 revised protocol、重新 protocol approval/freeze。
- confirmation/test 后原 program 全部研究写操作关闭，只允许 derive。
- migration 003/003b 使用 online backup、artifact manifest 和事务；失败注入证明部分 DDL 回滚。
- v1.1 缺失 profile 的 legacy run 保持可读并默认为 smoke。
