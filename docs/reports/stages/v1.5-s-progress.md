## 安全与故障验收

- 未认证请求和未允许 Origin 被拒绝。
- 非 loopback bind 未显式允许时启动失败。
- discovery 不含 token；默认 token file 权限为 `0600`。
- 外部 SecretProvider 不生成 token file，secret 原文不进入 SQLite/WAL。
- 默认 capability negotiation 报告 offline=true、telemetry=false。
- Python Job 因隐含网络能力在默认策略下被拒绝；Bubblewrap Job可提交。
- 拒绝和接受请求均写入权限、外部服务和脱敏 payload hash audit。
- Service 产生的 `job.submitted` 事件保存实际 filesystem/process 权限。
- SSE 成功传输 Project 事件和 Worker Job 日志。
- 服务停止删除 discovery，重启后同一 Project 可继续查询。
- TypeScript 本地客户端可自动启动并发现服务。
- Python SDK 和参考 CLI 均通过真实 TCP 服务完成验收。
- 参考 CLI 边界检查证明没有 Store、Workflow、migration 或 SQLite import。
- schema 15 迁移执行备份；损坏 migration 完整回滚至 schema 14。
- 全量 71 项测试通过，N–R 和既有科研门禁无回归。

## 已知限制

- SSE 使用轮询 read model；尚无消息代理或 WebSocket。
- 当前聊天规划器不产生真实模型 token delta。
- report CLI 汇总状态和事件，正式研究报告界面属于 v2.0 客户端。
- Core 不内置 TLS、多用户账号或云平台。
- Plugin/Job/Conversation 尚未进入完整 Project Bundle，T 阶段处理。
