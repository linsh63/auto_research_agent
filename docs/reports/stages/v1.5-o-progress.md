## 故障注入与验收

- schema 11 迁移成功前生成备份；注入损坏 SQL 时完整回滚至 schema 10。
- 重启后相同命令返回持久化原结果，不增加事件。
- 重用幂等键提交不同命令被拒绝。
- 领域状态成功、事件写入失败时 receipt 保持 pending；重试被 in-doubt 门禁阻止，领域对象没有重复创建。
- 跨 Workspace 查询被拒绝。
- 事件 sequence、payload hash、数据库 hash 和 projection hash 可审计。
- 投影损坏可被发现并从事件重建。
- Bundle 任意内容被篡改时导入失败。
- Bundle 跨独立数据库导入后保持问题、审批、状态和事件历史。
- fork 保持 root/parent/branch 信息，幂等重放不创建第二分支。
- 已知旧事件成功 upcast，未知事件版本被拒绝。
- 全量 48 项测试通过，旧科研门禁无回归。
