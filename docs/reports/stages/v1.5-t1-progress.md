状态：**完成，T1 门禁通过；T2a、T2b、T3–T5 尚未开始**

## 完成内容

- 新增 schema 16、Bundle v2、依赖 read model 和 Bundle v1 兼容路径。
- 覆盖 Project/Event/Projection、研究问题、证据、假设、protocol、study、统计、评审、决策、Conversation、Job、Artifact、插件锁和明确归属的 Project memory。

- 实现行、分区、插件、Artifact 和 Bundle 五层哈希检查。
- 实现 staging validation、Workspace 重映射、主键冲突检查和原子数据库导入。
- 实现 ready/degraded/blocked 兼容报告与 `project.dependencies`。
- exact plugin lock 可在用户安装启用后由 `plugin.runtime` 重新协调。
- Artifact 支持 embedded、content-addressed、missing 和 private-omitted。

## 安全与故障验收

- queued/running Job 阻止导出，终态 Job 可以迁移。
- confirmation token 原文和原 token hash 均未进入 Bundle。
- command receipt、service secret audit、lease 和 confirmation grant 被排除。
- 本地数据、Job workspace、绝对脚本、Pi session 和插件绝对路径被脱敏。
- 私有 Artifact 不内嵌；项目 Artifact 可校验后写入目标 CAS。
- 缺失插件产生 degraded，不会自动安装或执行；exact lock 启用后恢复 available。
- 被篡改的行、插件、Artifact 或根对象全部拒绝。
- 不兼容 core schema 和 Project ID 冲突均 blocked，目标不生成第二份 Project。
- secret-like conversation 内容会阻止导出。
- schema 16 迁移执行备份；损坏 migration 同时回滚新增表和 ALTER COLUMN。
- Bundle v1 明确请求时继续通过原有跨实例测试。
- 全量 76 项测试通过，N–S 与既有科研门禁无回归。

## 跨实例结果

完整 fixture 包含高级 study、已消费 confirmation、EvidenceMap/全文 passage、Project memory、Conversation、终态 Job、project/private Artifact 和插件锁。导入独立数据库后：

- Project 科研状态为 `confirmation_observed`；
- Project event/projection audit 通过；
- program、protocol、EvidenceMap、study 和 FactLedger 的科学 content hash 保持一致；
- Evidence source 和 Project memory 均存在；

- 再次导出仍保留插件锁和 Artifact requirement。
