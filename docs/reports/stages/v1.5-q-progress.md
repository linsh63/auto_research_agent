# v1.5 Q 阶段进度：Job/Worker 与 Pi 复用

状态：**完成，Q 阶段门禁通过；R–T 尚未开始**

## 完成内容

- 完成 Pi SDK 0.85.1 的 session、事件、取消、工具、插件权限和后台任务复用审计。
- 新增 schema 13 持久 Job、attempt、lease、heartbeat、日志、Artifact 和 confirmation grant。
- 实现 submit、cancel、retry、过期 lease 恢复和七类稳定失败原因。
- 实现 CPU、内存、磁盘、GPU 和墙钟资源请求与 Worker 容量分配。
- 实现语言无关 Worker request/result schema 和 Application worker 入口。
- 实现真实本地 Python runner，以及 Bubblewrap 和 Pi Job adapters。
- 实现 stdout/stderr/progress/system 流和内容寻址 Artifact 提交。
- confirmation token 只保存哈希，并且只向 Bubblewrap lease 开放封存数据。

## 故障注入与验收

- 真实 Python 子进程可输出日志并提交 CAS Artifact。
- 超时和运行中取消会终止进程组并释放 lease。
- Core/Store 重启后，过期 resumable lease 重新排队并以新 attempt 恢复。
- Worker 容量不足时不超配 CPU、内存、磁盘或 GPU，同一 GPU 不重复分配。
- data failure 可显式 retry；旧 attempt 的 lease token 不能修改新 attempt。
- malformed Artifact completion 被拒绝，Job 保持 running，随后可正确提交。
- Agent 和非 Bubblewrap executor 均不能取得 confirmation；正确 token 原文不进入持久状态或结果。
- confirmation mount 只在 capability 消费后的 lease 中出现。
- Pi adapter 将事件转成 Job 日志，并把取消传给 AgentSession abort。
- schema 13 迁移执行备份；损坏迁移完整回滚至 schema 12。
- 全量 61 项测试通过，N–P 和既有科研门禁无回归。
