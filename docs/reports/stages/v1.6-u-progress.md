# v1.6 U 阶段：七类公共科研能力

状态：**完成**

## 交付

- 新增 `capability.catalog` 与严格 discriminated `capability.invoke` 公共合同。
- Core Service、进程内 Application、TypeScript Client 和 Python Client 共享同一 command/query transport。
- 新增七类确定性能力实现，并复用 EvidenceStore、MemoryStore、FactLedger 和已验证领域门禁。
- 所有成功调用产生 `capability.invoked`，失败调用产生 `command.rejected`。
- Evidence 与 memory 使用 Project 前缀和返回过滤，跨 Project 检索为空。
- draft Project 被 scope gate 拒绝；memory review/verify 只能由用户执行。
- 公共 JSON Schema 与 Python 生成模型已同步。

## 科研与安全边界

- 文献 success 同时执行 ingest、FTS search 和 supported claim check；无引用事实被拒绝。
- novelty overclaim、缺失 null hypothesis、未控制混杂、重复 unit、未审核 memory 和自由数值写作均被拒绝或隐藏。
- 统计结果只给出配对实验单位描述性 estimand，没有自动提升为总体因果结论。
- 这些接口使能力可被上层调用，不代表模型自动完成相关科研判断。
