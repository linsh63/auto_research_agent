## 科学过程

- 使用与 v1.3 完全不重叠的 80 个探索图像和 80 个封存确认图像。

- 候选冻结后才签发并消耗确认能力；成功确认运行使用 Bubblewrap、禁网和单 GPU 映射。

## 主要发现

纯问题语义路由准确率为 0.9236，图像与问题联合路由为 0.6847，均未达到冻结门槛。Agent 进一步发现 RIO 的 object-ignore 条件采用多选回答，而 text-read 条件采用开放答案，因此任务需求与回答格式存在构念混杂。

受限于 RIO 回答格式的冻结路由在封存集达到 1.0 路由准确率。三个模型的候选相对 direct 联合效应分别为 0.0667、0.0264 和 0.0292；跨模型、图像聚类的效应为 0.0407，95% 区间为 [0.0246, 0.0569]，独立单位为 80 个原始图像。

该结果只支持 RIO 格式内的 replication/transport，不支持通用语义路由、跨数据集泛化、因果机制或方法新颖性。

## Agent 与基础设施改进

- 新研究默认要求 `bubblewrap_required`，trusted-only confirmation 无法发布。
- Bubblewrap runner 支持明确的多 GPU 列表与 GPU 时间核算。
- Pi JSON 解析器现在能提取模型在尾随思考文本之前返回的首个平衡 JSON 对象，并有回归测试。
- 真实运行识别并保留了 OCR 环境挂载失败、32B 跨卡 hook 归零、变尺寸批处理不兼容等失败分支。
- 32B 最终采用经过烟雾验证的单 GPU int8 权重、bfloat16 计算配置；模型权重只读缓存不进入 Git。
- 最终结果经过 FactLedger、图像聚类分析、实际 LLM 解释、证据/方法/统计/复现四维评审和 fail-closed 发布验证。
