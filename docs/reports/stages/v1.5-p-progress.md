# v1.5 P 阶段进度：聊天、候选与执行策略

状态：**完成，P 阶段门禁通过；Q–T 尚未开始**

## 完成内容

- 定义公共 ResearchAction、候选集合、Conversation 和 ExecutionPolicy 契约。
- 将直接 API、候选点击和自动聊天统一到同一个行动执行器。
- 实现 `manual`、`candidate`、`auto` 三种 Project 级持久策略。
- 候选列表固定以自由输入结尾，自由输入会创建新一轮消息和候选。
- 持久化 Session、消息、候选、行动审计和策略，并提供查询 read model。
- schema 12 migration 包含在线备份与原子失败回滚。
- 新增独立 JSON Schema，供后续 Service、TypeScript SDK 和 Python SDK 使用。

## 门禁验收

- 三个独立 Project 分别通过直接 `action.execute`、用户候选点击和 `auto` 聊天提出相同研究问题。
- 三种入口产生相同 `question.proposed` 事件类型和语义相同的 ResearchAction payload。
- 自动策略在范围审批处停止，只返回人工候选。
- Agent 直接执行或点击 `scope.approve` 均被拒绝；用户明确选择后才进入 `scoped`。
- 自由输入是候选集合最后一项，消费后生成新候选；重启后会话、消息和策略可恢复。
- schema 12 迁移成功前创建备份；损坏迁移完整回滚至 schema 11。
- 全量 53 项测试通过，N/O 和旧科研门禁无回归。
