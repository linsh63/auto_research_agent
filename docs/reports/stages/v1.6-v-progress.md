# v1.6 V 阶段：跨平台基础与 capability negotiation

状态：**完成，V 全部门禁通过；下一阶段为 W**

## 完成内容

- 公共 `PlatformCapabilitySnapshot` 进入服务 capabilities、Worker descriptor、JSON Schema 和 Python SDK。
- 自动探测 Linux/macOS、arch、Python、Bubblewrap、prlimit、process tree、storage、OpenSSH、SFTP、ProxyJump 和 multiplexing；Windows 仅保留 unsupported 识别。
- Job 增加可选 platform constraints；调度同时匹配 executor/platform/GPU/sandbox/storage。
- 显式平台 Worker 缺能力时保持 Job queued，不回退执行器。
- 新旧 Worker 兼容：旧 descriptor 只领取无平台约束任务。
- Python 默认命令和 POSIX process-group 终止适配 Linux/macOS。
- Artifact/script portable path 拒绝 drive、UNC、绝对路径、traversal、空 segment 和换行，保留带空格相对路径。
- 增加 Ubuntu x64、macOS arm64、macOS x64 GitHub Actions matrix。

## 实施过程

1. 首轮 Linux CI 因 runner 默认未安装 Bubblewrap而正确报告 unavailable；矩阵随后显式安装 Bubblewrap再执行 capability gate。
2. 原 Windows 试验在 `npm ci` 暴露 Pi/SQLite 原生依赖安装问题。Pi 已改为 optional executor，基础 Core 不再受其失败阻塞。
3. 用户随后将 v1.6 支持范围收敛为 Linux + macOS。Windows 从矩阵和完成定义移除，防御性路径/进程检查保留但不构成支持承诺。
