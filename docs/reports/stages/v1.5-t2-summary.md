## T2 结论

- **公共模块边界成立**：两个 Scenario 和 runner 均通过 import 边界扫描，没有访问内部 Store、Workflow、Domain、migration 或数据库驱动。

- **科研语义未被执行抽象抹平**：两例分别保留原始实验单位、数据角色、结果来源和主张边界。
- **移植性成立**：两例都能将结果 Artifact 内嵌到 Bundle v2，并在第二个空白实例中恢复为 available。
- **能力结论仍有边界**：T2 是场景迁移验收，不是十二维科研能力评分；该问题留给 T3。
