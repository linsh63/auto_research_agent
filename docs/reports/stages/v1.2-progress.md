## E 阶段过程记录

### 步骤 1：ADR 与对象边界

新增 [ADR 002](../../architecture/decisions/002-e-research-state-and-compatibility.md)，确定 `ResearchProgram → ResearchQuestion → ResearchProtocol` 版本图、canonical hash、v1.1 只读兼容和 confirmation 后派生规则。

### 步骤 2：schema 与 migration

- 新增 `src/domain/research.ts`：profile、program、question、assumption、protocol、approval、freeze、deviation、visibility、derivation schema。
- 新增 `schemas/research/research.v1.json`，作为跨进程对象契约的 JSON Schema 参考。
- 新增 `migrations/003_research_protocol.sql` 和 corrective `003b_research_cognitive_objects.sql`，数据库版本从 2 升至 4。
- `ResearchStore` 使用 SQLite online backup API，并生成 `.research-data/backups/` 下的数据库备份与 artifact manifest snapshot。
- Ledger 和 EvidenceStore 接受版本 4，旧表继续可读。
- 新增 AssumptionRegister/HypothesisSet aggregate、confirmation 后 mutation guard、deviation resolution 和 maxDerivedRuns 门禁。

### 步骤 3：工作流不变量

新增 `WorkflowCoordinator` 和 `ResearchStore`，实现：

- ResearchIntent 创建 program；
- 问题候选创建、选择和旧版本 supersede；
- scope approval；
- protocol draft、approval 和 freeze；
- deviation 追加记录；
- confirmation/test visibility 一次性登记；
- visibility 后禁止 exploration；
- 派生 program 保存父关系、原因和 observed data。

### 步骤 4：profile 与配置

- `ResearchBrief.profile` 新增 `smoke | exploratory | confirmatory`，旧 brief 默认 `smoke`。
- ResearchIntent 默认 `confirmatory`。
- `config/defaults.yaml` 和 Zod config 增加研究 profile、派生 run 上限和 baseline/rival 要求。
- package version 更新为 `1.2.0-alpha.1`。

### 步骤 5：CLI 与测试

新增 `research` CLI 命令组，覆盖 intent、question、scope approval、protocol、freeze、deviation、visibility、derive 和 status。新增 E 契约测试覆盖：

- 迁移备份、artifact manifest 和 schema version 3→4；
- v1.1 Ledger/EvidenceStore 只读兼容；
- 未审批不能 freeze；
- frozen protocol 不能二次 freeze；
- confirmation visibility 后不能探索；
- 重复 confirmation visibility 被拒绝；
- 派生 run 记录父关系和已观察数据；
- 旧 brief 默认保持 smoke；
- 默认配置 schema 正确加载。
- CLI create/status contract、schema 3→4 corrective migration 和真实 legacy brief readback 均通过。
- CLI smoke 已实际创建 confirmatory program，并验证研究数据库版本为3、program记录可读。

### 回滚登记

E migration 之前由 `ResearchStore` 在同一数据目录的 `backups/` 下创建数据库副本。回滚操作只针对停止服务后的副本：先复制阶段前 backup 到新的验证目录，运行 schema/version 检查和旧 CLI readback，确认后再切换应用使用的数据库路径；不在原库上覆盖恢复，也不删除已生成的新 artifact。

## H 阶段过程记录

### H1：review、claim 与决策基础设施

- migration 006 将 schema version 升至 7，新增 model role/session invocation、ClaimAssessment、validity threat、四维 review、response、decision 和 reproduction manifest。
- `ReviewWorkflow` 使用独立只读 pi session 执行 evidence、methods、statistics、reproducibility review；保存 provider/model、输入 hash、原始输出、usage、成本和失败。
- major finding 未响应时阻止最终决策；invalid review 阻止 `publish_bounded_result`。
- 新增 protocol draft revision，修复草案会生成新版本并保留旧版本。
- H CLI 与 `schemas/research/review.v1.json` 已接入。

### H2：真实研究范围与 protocol

- 用户输入只包含单 GPU 下研究小型 CIFAR-10 分类器分布偏移鲁棒性或校准的方向。
- 本地 DeepSeek-R1-Distill-Qwen-7B 通过 pi provider/runtime 生成问题候选；1.5B 模型和早期 schema 不合格输出作为失败保留。
- 第一人工门选择 AugMix 与 standard training 的 mean corruption accuracy 问题。
- 四篇 primary full text 已下载、解析和写入 EvidenceMap；coverage 明确标记 incomplete，novelty 保持 unresolved。
- 实际 LLM 生成 target/null/rival、assumptions 和 protocol。自动审查发现模型提出 p-value optional stopping，保留 v1 草案并生成移除该规则的 v2。
- 第二人工门批准并冻结 protocol v2：ResNet-18、seeds 11/23/47、固定 12 epochs、seed-by-corruption 配对分析。

### H3：真实实验与环境整改

- exploration 只挂载 CIFAR-10 train/validation、brightness severity 3 和 defocus blur severity 3；Gaussian noise、contrast 与 clean test confirmation role 保持 sealed。
- baseline 三颗 seed 均通过 clean validation ≥0.65 门：11=0.8894、23=0.8850、47=0.8944。
- 当前主机所有 GPU 的 cuDNN 初始化均返回 `CUDNN_STATUS_NOT_INITIALIZED`；固定改用原生 CUDA convolution。
- bubblewrap DataLoader 多进程兼容失败后固定单进程读取；AugMix 三路前向使用 activation checkpointing。
- `RLIMIT_CPU` 按线程累计导致的 exit 137 已定位，PyTorch/BLAS 线程固定为4；失败 run 全部保留。
- AugMix seed 11 已成功：exploration mean corruption accuracy 0.8702，对应 baseline 0.84145；其余种子仍按 concurrency=1执行，单 seed 结果不作为最终结论。
- 当前全量测试 28/28 通过，包含 migration 006 失败原子回滚。

### H4：confirmation、claim 与最终决定

- 三颗 AugMix exploration seed 全部成功；候选相对 baseline 的探索差值为 +0.02875、+0.04840、+0.03635。
- 第三人工门批准 CandidateFreeze；一次性 confirmation token 只签发和消费一次。
- 六个冻结 checkpoint 在 clean test、Gaussian noise severity 3、contrast severity 3 上各评估一次，未重新训练。
- primary estimate 为 +0.14757，95% interval [0.11128, 0.18386]；n=3，leave-one-seed-out方向稳定。
- 实际 LLM 完成有界解释与 evidence/methods/statistics/reproducibility review。10条 findings 全部响应，open finding=0。
- ClaimAssessment grade 保守登记为 suggestive；一个架构、三颗seed、两个group和一个severity是显式限制。
- 第四人工门批准 `publish_bounded_result`；最终报告、claim matrix、validity threats、deviation log和reproduction manifest均已生成。
- 总模型调用15/20（9成功、6失败），已知成本0 USD；resource usage约3.374 GPU小时；案例目录约855 MiB。
