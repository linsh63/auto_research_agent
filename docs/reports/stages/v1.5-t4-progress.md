## 包边界

候选包只包含公共入口所需的编译运行时、迁移、公共 JSON Schema、Python SDK/Worker、五份安装后指南和许可证文件。它不包含源码、测试、脚本、案例、benchmark、数据库、缓存、secret、数据集、模型权重或研究 Artifact。内部编译模块只作为公共 facade 的运行依赖存在，未加入 `exports`。

最终 tarball 细节以 [T4 package audit](../validation/t4-package-audit.json) 为准。tarball 保存在忽略版本控制的 `.research-data/t4-release/`，不会提交仓库。
