# v1.5 N 阶段进度：公共契约与包边界

状态：**完成，N 阶段门禁通过；O–T 尚未开始**

本报告保留 N 阶段完成时的快照；其中 Workspace、幂等和事件未持久化等限制已由 [O 阶段](v1.5-o-progress.md)解决。

## 完成内容

- 新增 `src/public/contracts.ts`，定义版本化 Command、Query、Result、Error、read model 和 Event envelope。
- 新增 `src/public/kernel.ts`，实现 schema 版本、上下文和稳定错误语义。
- 新增 `ResearchApplication`，用最小兼容 facade 包装已有科研状态机。
- 公共流程已覆盖 Project 创建、问题提出、问题选择、范围批准和状态查询。
- 新增进程内幂等保护；相同 key 的不同命令返回 `CONFLICT`。
- 新增 Workspace–Project 隔离；跨 Workspace 查询返回 `FORBIDDEN`。
- 旧 Project 只能通过显式 compatibility binding 接入，未知绑定 fail closed。
- 根包新增显式 public exports，构建生成 JavaScript 和 TypeScript declaration。
- 生成 `schemas/public/v1/` JSON Schema 2020-12 和 SHA-256 manifest。
- 新增公共依赖边界检查，只给兼容 facade 两个内部依赖例外。

## 门禁验证

- 仅通过 ResearchApplication 完成最小 scoped research flow。
- 公共 schema 缺字段时返回 `INVALID_COMMAND`。
- 不兼容 schema 版本返回 `INCOMPATIBLE_VERSION`。
- 未满足范围门禁时返回 `GATE_REJECTED`。
- 跨 Workspace 查询被拒绝。
- 幂等重放返回原结果，冲突重放被拒绝。
- 重启后旧 Project 无绑定时不可访问，显式绑定后可读取。
- JSON Schema 生成和陈旧检查通过。
- TypeScript 类型检查、声明构建和依赖边界检查通过。
