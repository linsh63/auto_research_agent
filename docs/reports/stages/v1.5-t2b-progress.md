## 实施过程和故障记录

1. 先核对既有准备目录，四个执行输入的大小和 SHA-256 均与 source lock 一致。
2. 首次服务试跑因 `gpuHours=0` 不满足公共 Intent 正数预算 schema，被客户端在发送前拒绝。
3. 将“无 GPU”表达为 `gpuCount=0` 的执行资源约束，并把项目 GPU 预算上限设为 0.001；再次运行通过。这个数值不是实际 GPU 用量，实际运行仍为零。
4. Job 使用 `exploration` 数据角色。T2b 没有创建完整 Study 和一次性 confirmation token，因此不冒充核心确认运行；固定测试协议和描述性结论边界单独记录。
5. Bundle 导入状态为 `degraded`，唯一问题是终态 Job 的环境路径按 T1 规则脱敏，历史和 Artifact 均可读。
